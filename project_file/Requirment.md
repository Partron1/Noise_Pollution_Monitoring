### Operating system
- Windows, macOS, or Linux

### Hardware 
- Arduino UNO, MQ135 gas sensor (for air quality), sound sensor module (for example, KY-037 or KY-038), ESP8266 for wifi communication
- Upload arduino_sensor.ino to Arduino IDE and flash to your microcontroller

### Software
- Python: Version 3.7 or higher
- Raspberry Pi OS (if using Raspberry Pi for deployment)
- Flash Arduino with arduino_sensor.ino using Arduino IDE
- Code reads air quality and sound and sends data over wifi to Firebase
- IDE/Environment
- VS Code with Python extension
- Thonny (for Raspberry Pi development)
